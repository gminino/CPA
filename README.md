# Club Paraíso Animal (CPA)

Repositorio de documentación del proyecto **Club Paraíso Animal** y su estructura comercial asociada, **Kninord Holding SRL**, liderado por Guillermo Emigdio Miniño Álvarez — Villa Soñador, Bonao, República Dominicana.

## Propósito de este repositorio

Centralizar la documentación legal, financiera, operativa y de visión de CPA para:

- Ordenar y dar trazabilidad al trabajo interno del proyecto.
- Servir de base de consulta y trabajo para la elaboración de materiales de presentación ante potenciales socios, colaboradores e inversionistas.

## Estructura del proyecto

- **Kninord Holding SRL** — estructura comercial.
- **Club Paraíso Animal (CPA) ASFL** — estructura sin fines de lucro (en proceso de constitución legal).

## Estructura de carpetas sugerida

```
/01-legal/           → constitución, estatutos, contratos, registros
/02-financiero/       → proyecciones, presupuestos, modelo de ingresos
/03-operativo/        → protocolos y manuales (SRK, FAMACHA-K, etc.)
/04-presentaciones/   → resúmenes ejecutivos, pitch decks, propuestas
/05-medios/           → fotos, video, prensa, documentación audiovisual
```
